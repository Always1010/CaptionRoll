# CaptionRoll

CaptionRoll 是一个适用于 Microsoft Edge 和 Google Chrome 的 YouTube 英文文字稿增强扩展。

## 当前功能

- 打开普通 YouTube 视频页时默认显示醒目的文字稿面板。
- 宽屏时停靠在视频右侧；YouTube 将侧栏移到下方时随页面布局移动。
- 自动选择并加载优先级最高的英文字幕轨道。
- 文字稿独立于播放器 CC 开关加载，不会修改用户的字幕开启状态或所选轨道。
- 捕获播放器自己的 timed-text 请求，兼容当前字幕来源验证机制。
- 将 YouTube 的碎片字幕智能合并成更完整的英文句子。
- 当前字幕自动高亮并居中跟随。
- 用户滚动后暂停跟随，点击“回到当前字幕”恢复。
- 点击任意字幕跳转到对应视频时间。
- 在扩展设置弹窗中切换“跳转模式”和可复制文字的“选字模式”。
- 收藏完整英文句子，并在面板内集中选择或删除；视频标题、时间点和来源链接一并保存在本机。
- 为所选收藏按需生成中文提示，也可以在导出前手动编辑。
- 将卡片整理为“中文提示 → 英文原句”，一键复制并打开 Quizlet 创建页。
- 通过工具栏设置弹窗调整面板显示、交互方式、字号、跟随与默认展开状态。
- 支持面板收起，以及 YouTube 站内无刷新切换视频。
- 所有处理均在浏览器本地完成，没有后端，也不会上传字幕或浏览记录。

## 在 Microsoft Edge 中安装

1. 在地址栏打开 `edge://extensions`。
2. 打开左侧或页面中的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目目录，也就是包含 `manifest.json` 的 `CaptionRoll` 文件夹。
5. 打开或刷新一个 `https://www.youtube.com/watch?v=...` 视频页面。

修改代码后，在扩展管理页点击 CaptionRoll 的“重新加载”，然后刷新 YouTube 标签页。

## 在 Chrome 中安装

步骤相同，只需打开 `chrome://extensions`，然后选择“加载已解压的扩展程序”。

## 使用说明

- 点击浏览器工具栏中的 CaptionRoll 图标打开设置弹窗。
- 可以在设置中控制文字稿是否显示、交互模式、字号、自动跟随与默认展开状态。
- 点击标题栏右侧箭头可以收起或展开。
- “跳转模式”下点击字幕会定位视频；“选字模式”下可以拖动选择并复制字幕文字。
- 点击完整句子右侧的星标即可收藏；点击面板标题栏中的星标进入收藏夹。
- 在收藏夹勾选句子，点击“生成中文”。首次使用时 Edge 可能需要下载本地翻译模型。
- 检查中文后点击“复制并打开 Quizlet”，再在 Quizlet 创建页选择“导入”并粘贴。
- 如果浏览器暂不支持本地 Translator API，可以直接在每张卡片的中文输入框中填写，不影响 Quizlet 导出。
- 没有软字幕轨道、只有烧录字幕的视频无法读取。

## 隐私与权限

扩展只申请 `youtube.com` 页面访问权限和本地设置存储权限。字幕解析、句子合并、收藏与支持时的翻译均在本机完成；导出时只把卡片写入剪贴板并打开 Quizlet 创建页。
